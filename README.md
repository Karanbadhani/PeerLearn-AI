# PeerLearn AI - Advanced SIH Prototype

This is a self-contained frontend prototype designed for quick SIH demonstration.

## What works
- Signup
- Login
- Demo login
- Logout
- Profile editing
- Responsive desktop/mobile layout
- Tutor discovery
- Smart filters
- Simulated NLP smart search
- Tutor match score
- Booking system
- Persistent bookings using localStorage
- Skill verification quiz
- Verified tutor badge
- Learning gap dashboard
- Simulated LLM learning companion
- AI flow and recommendation screens

## How to run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the "Live Server" extension if you do not already have it.
4. Right-click `index.html`.
5. Choose "Open with Live Server".

You can also double-click `index.html`, but Live Server is recommended.

## Important
This is a working frontend prototype. Login, booking, profile and verification use browser localStorage.
The AI/NLP/ML behavior is simulated for prototype demonstration.

For production:
- Backend: Python + FastAPI
- Database: PostgreSQL
- LLM: Gemini/OpenAI API
- ML: Python + Scikit-learn
- Authentication: JWT / OAuth
